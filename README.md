# Hexert Cybersecurity - Company Website

This is a modern, single-page, responsive website for a fictional cybersecurity company called "Hexert". The design is dark, professional, and incorporates tech-themed aesthetics and animations.

## Live Demo

You can view a live demo of the website [here](https://<Your-GitHub-Username>.github.io/hexert-website/).
*(Replace `<Your-GitHub-Username>` with your actual GitHub username after deploying.)*

## Features

-   **Fully Responsive:** Looks great on all devices, from mobile phones to large desktops.
-   **Dark Mode Theme:** A modern and professional dark theme suitable for a cybersecurity company.
-   **Smooth Scrolling & Active Link Highlighting:** Easy navigation with visual cues for the current section.
-   **Interactive Animations:**
    -   Page preloader
    -   Animated hero statistics (count-up effect)
    -   Fade-in effects for sections as you scroll
    -   Subtle animations on buttons, cards, and UI elements.
-   **Pure HTML, CSS, and JavaScript:** No frameworks or libraries needed, making it lightweight and easy to understand.
-   **SEO Friendly:** Includes meta tags for description and keywords.
-   **Clean Code:** Well-structured and commented code for easy modification.
